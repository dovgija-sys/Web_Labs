Довідка DevGuard API

Розділи довідки

DevGuard API — демонстраційний сервіс для інтеграції перевірок безпеки у вебзастосунки.

  • Перевірка вхідних запитів.
  • Централізоване налаштування захисту.
  • Журналювання подій API.

Додайте AddSecurityCore() до конфігурації сервісів, налаштуйте параметри та перевірте інтеграцію тестовим запитом.
